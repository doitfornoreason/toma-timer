# context

- This project is a a lighting fast, lightweight pomodoro timer with a simple, clean interface and a focus on data exportation, data visualisation, and analysis. 

- This project will be initially driven by you, to choose the best approach to plan, and implement the timer. 

- Requests:
    - Make a GUI with a clean, simple interface that can be toggled from dark mode to light mode
    - Make the timer lightweight and fast, with a focus on performance and low resource usage
    - Create a logging system that records the time spent on each pomodoro session, and allows for easy exportation of this data in a variety of formats (e.g. CSV, JSON, etc.)
    - The logging system should also allow for easy visualisation of the data, with graphs and charts that show trends and patterns in the user's pomodoro sessions over time
    - The timer should be highly customisable, allowing the user to set their own pomodoro session lengths, break lengths, and number of sessions per day
    - No need for visual notifications, but a simple sound notification when a session ends would be nice
        - with a custimisable mp3/flac that can be chosen as the sound effect
    - The timer should be able to run in the background, allowing the user to continue working on other tasks while the timer is running, and should be pausable, restartable, and resettable at any time
    - Id like a second tab/redirection to a "stats" page that shows the user's pomodoro session history, with graphs and charts that show trends and patterns in their productivity over time
        - Please also include metrics like average session length, total time spent on pomodoro sessions, and number of sessions completed per day/week/month, most productive times of day, and any other relevant metrics that can help the user understand their productivity patterns and habits

- Please plan out the steps you will take to implement this project, and wait for confirmation or revision of the plan before execution.
